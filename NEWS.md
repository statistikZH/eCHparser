# eCHparser (development version)

# eCHparser 0.1.0

* Function to create XLSX template files for majority and proportional elections

* Builder function to turn election dataframes into valid XML files in the format of eCH-0157

* Various wrapper functions to read and enrich template files or directly convert templates from XLSX to XML

# eCHparser 0.0.1

* Parser function to turn vote result files in the format eCH-0252 into dataframes

* Parser function to turn election files in the format eCH-0157 into dataframes
